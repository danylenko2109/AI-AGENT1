# FirstAI Premium AI Automation Agency Website

Production-ready React + Vite website for **FirstAI**, a premium AI automation agency positioned like a serious AI startup / SaaS company.

## Stack

- React + Vite
- TailwindCSS
- Framer Motion
- Lucide React Icons
- Responsive component architecture

## Commands

```bash
npm install
npm run dev
npm run build
```

## Deploy

Ready for Vercel. Build command: `npm run build`, output directory: `dist`.
